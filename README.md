# Apna Clinic

Pakistan hybrid clinic platform — online video/chat consultations and in-clinic visits.

## Self-hosted video consultations

Production video can use self-hosted Jitsi Meet with Prosody JWT authentication,
or 8x8 JaaS. Deployment notes for self-hosted Jitsi are in
[`deploy/jitsi/README.md`](deploy/jitsi/README.md).
